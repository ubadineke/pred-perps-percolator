# Moxie SDK

Typed encoders cover market activation, pricing, resolution, portfolio creation,
deposit/withdrawal, matcher quotes, opening/closing TradeCpi orders, permissionless cranks,
hard-flat settlement, and resolved close. Account decoders expose imported-market
lifecycle/pricing plus portfolio collateral, PnL, funding, active legs, and health certificates.
All protocol amounts remain integer `bigint` values until UI formatting.
